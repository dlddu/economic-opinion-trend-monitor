# 주석 정책 — 복원 가능한 내용을 되풀이하지 않는다

이 저장소의 주석은 **코드 · 저장소 문서 · PR · 커밋 메시지 어느 쪽으로도 복원되지 않는 지식**만 담는다.
다른 곳에서 확인할 수 있는 내용을 되풀이하는 주석은 값이 없을 뿐 아니라, 원본만 고쳐질 때 조용히
거짓이 된다(첫 판정에서 실제로 `suspend: false`인 CronWorkflow 위에 "suspend로 착지한다"는 주석이
남아 있었다).

이 디렉터리는 세 역할을 파일로 나눈다.

| 파일 | 역할 |
|------|------|
| `README.md` (이 파일) | 정책 본문 — 복원 경로, 유지 대상, doc 주석 수준, 기계가 읽는 주석, 판정 절차 |
| [`ledger.md`](ledger.md) | 판정 원장 — 파일 단위로 몇 줄이 판정됐고 무엇이 남았는가 |
| [`passes/`](passes/) | 판정 상세 — 판정일별로 제거 근거, 유지 목록, 판단이 갈려 남긴 것 |

## 복원 경로 넷

1. **코드 자체** — 식별자 이름, 시그니처, 바로 아래 선언·단언
2. **저장소 문서** — `README.md`, `docs/`(PRD·테스트 문서·doc-tracker·디자인 시스템), `contracts/` 스키마
3. **PR** — 제목·본문·리뷰 코멘트
4. **커밋 메시지**

이 중 어디서든 확인되는 내용은 주석의 자리가 아니다. 주석이 원본과 어긋나면 **주석이 틀린 것으로 본다**.

## 유지 대상

- **기계가 읽는 주석** — 정책 대상이 아니며 지문·판정 모두에서 제외한다.
  - `// 검증 시나리오:`(및 이관 전 `// 검증 AC:`) — `tests/e2e/check_scenario_mapping.py`가 파싱한다.
  - shebang, `//go:` 빌드 지시자, `# type:` · `# noqa` · `eslint-` · `@ts-` 같은 타입 검사기·린터 지시자.
  - `mock-exception:` — e2e 목킹 정책의 표기 규약.
  - Makefile 타깃 줄의 `## 설명` — `make help`가 읽는다(줄머리 `## --- … ---` 구분선은 읽히지 않으므로 해당 없음).
- **doc 주석**
  - Go: export 식별자의 **이름으로 시작하는 1줄** doc 주석과 패키지 주석.
  - Python: 모듈·public 함수 docstring, 모듈 속성의 `#:` 주석.
  - TS: export 함수·타입의 JSDoc 요약 1줄.
  - 다만 본문이 시그니처·`contracts/` 스키마·PRD·README「범위」를 되풀이하는 부분은 제거 대상이다.
- **복원 불가능한 지식**
  - 외부 수집원(RSS/Atom)과 chat-completions 엔드포인트의 문서화되지 않은 동작
  - 데이터 계약의 비자명한 성질(예: Gold 버킷 키의 사전식 정렬이 시간순과 같아지는 조건)
  - 클러스터·런타임 제약(예: RWO 볼륨과 `Recreate`, runc가 read-only 마운트 안에 mountpoint를 못 만드는 것,
    efs StorageClass의 PVC 이름 기반 access point 재사용, kustomize `images:`가 WorkflowTemplate 경로를 모르는 것)
  - 스케줄 계약의 근거(누락 보정, 동시 실행 금지)
  - 픽스처가 실환경과 갈리는 지점, 테스트가 **왜 그 모양으로** 단언하는지
  - 편집 지점에서만 효과가 있는 가드(예: "이 태그는 CI가 관리한다 — 손으로 고치지 않는다").
    가드는 **메커니즘을 담지 않는다** — 어디에 커밋되는지·무엇을 추적하는지는 복원 가능하고, 그 경로가
    바뀌면 가드가 조용히 거짓이 된다(2026-09-18 pin-guard-pass). 같은 이유로 **개수·열거·행 위치**도
    담지 않는다("두 `image:` 줄", "아래 세 곳", "47·99행") — 파일이 자라면 그 표현이 조용히 거짓이 되고,
    가드는 아무도 검증하지 않으므로 거짓인 채로 남는다. 가드는 금지만 말하고 출처를 가리킨다.

## 판정 절차

1. 대상 주석을 뽑는다 — 범위는 `contracts go python/packages web/src tests scripts deploy Makefile`,
   codegen 산출물(`go/gen/`, `econ_core/models/`)과 데이터·스키마·잠금·마크다운 파일은 제외.
2. 주석마다 복원 경로 넷을 확인한다.
   - 복원 가능 → 지운다.
   - 원본이 부실해서 복원이 안 되는 것 → 주석을 남기는 대신 **원본(문서·이름·커밋 메시지)을 고친다**.
   - 복원 불가능 → 남긴다.
   - **애매하면 남긴다.** 중복 주석의 비용은 작지만 유일한 지식을 지우면 어디에도 남지 않는다.
     판단이 갈린 주석은 남기고 그 사실을 판정 상세에 적는다.
3. 원장(`ledger.md`)을 갱신하고, 판정 상세를 `passes/<판정일>-<slug>.md`로 남긴다.

자주 나오는 제거 유형:

- **구분선** — `// --- handlers ---`, `# ------ 결과` 같은 장식. 절 이름은 아래 함수·타깃 이름이 복원한다.
- **README 재진술** — 적용법(`kubectl apply -k …`), suspend 착지 절차, "나머지 화면은 플레이스홀더" 같은 범위 서술.
- **다른 파일 주석의 재진술** — 같은 설명이 러너와 시나리오 양쪽 머리에 있는 경우, 설명의 주인(러너)에만 둔다.
- **작업 흔적** — 파일 머리의 AC·슬라이스 배너, 폐기된 식별자(`J1`~`J5`)를 담은 줄. 해당 연결은
  테스트 문서의 `검증 AC` 필드와 doc-tracker의 e2e 매핑이 복원한다.

## 범위 밖 · 알려진 사각지대

- codegen 산출물의 주석은 대상이 아니다 — 고칠 곳은 생성기(`contracts/codegen.py`)다.
- `docs/`의 마크다운·HTML, `Dockerfile*`, `.github/workflows`, 라이선스 헤더는 대상이 아니다.
- 주석의 **정확성**은 이 정책의 판정 표면이 아니다. 다만 되풀이된 주석이 낡아 틀려 있으면 제거 근거가 강해진다.
- 지문(주석 줄 추출)이 보지 못하는 것: **Python docstring 본문**, 줄 끝 주석, 줄 중간에서 시작하는 블록 주석.
  docstring 재진술이 주요 중복 유형으로 드러나면 docstring을 별도 표면으로 판정에 더한다.
- 지문 패턴은 줄머리 `#`·`*`로 시작하는 **비주석**도 잡는다(`tokens.css`의 `* {`, `#root {`). 원장에 오탐으로 적는다.
