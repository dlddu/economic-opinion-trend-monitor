## 판정 축을 유지하는 근거

판정 축은 「이 주석이 ①~④ 어디에서 복원되는가」에 대한 판정이다. 치환은 **같은 대상을 가리키는 이름**만
바꿨고, 가리키는 대상(AC 본문·시나리오 본문·spec 파일)은 이 PR 안에서 새 이름으로 함께 옮겨졌다. 복원
경로의 존재 여부가 바뀌지 않으므로 판정을 다시 할 사유가 없다.

치환이 **식별자 토큰에 한정된다는 것**은 리터럴 신뢰가 아니라 역치환으로 확인했다: 이 PR 이 바꾼
`docs/` 밖 파일 50개 중 48개는 새 내용에 역대응(신→구)을 적용하면 `ed12baa` 의 원문과 **바이트 동일**하다.
나머지 2개(`interest-trends-6-three-axis-compare.spec.ts`·`fairness-2-normalized-ratio.spec.ts`)는
머리의 PRD 경로를 분할된 두 PRD 중 해당 쪽으로 바꾼 한 줄씩이 더 있다 — 대상 PRD 가 둘로 나뉘어
역대응이 한 값으로 정해지지 않는 유일한 곳이다.
