  ([judgment-debug-screen-pass](2026-09-28-judgment-debug-screen-pass.md) 의 `compareRows` 처분과 같은 잣대).
  `niceStep` 의 「1·2·2.5·5」 는 `TrendChart` 안 눈금 근거 주석과 PR #204 본문의 세 번째 사본이기도 하다.
- **제거 — `bucketTick` JSDoc 연속 줄**(「당일은 시만, 여러 날이면 날짜까지」). 본문의 `multiDay` 분기가

  수십~수백 개인 시간 단위에서 버킷마다 라벨을 찍으면 겹친다) — PR #204 본문은 「최대 7개만」 이라

### `Trend.test.tsx`

- **제거 — `seriesResponse` JSDoc.** 시그니처 `(buckets, shares)` 와 단일 계열을 짓는 본문이 복원한다(①).
  미export 테스트 헬퍼 — `renderTrend` · `legendNames` 를 걷은 잣대와 같다.
- **제거 — 100 버킷 픽스처 나레이션.** 바로 아래 `length: 100` · `Date.UTC(2026, 8, 24, 2)` ·
  `3_600_000` 과 단정 `"09-28 05시"` 가 복원한다(①).
- **유지 — `[hidden]` 단언 머리 3줄.** 배너가 `display` 를 스스로 선언해 UA `[hidden]` 을 이긴다는 것과
  jsdom 이 `!important` 를 캐스케이드에 반영하지 않는다는 **런타임 제약**, 그래서 계산된 스타일이 아니라
  토큰 문면을 단언한다는 **왜 그 모양으로 단언하는지** — 둘 다 유지 대상 열거에 있다. PR #204 본문 첫
  불릿이 같은 명제를 적어 ③ 히트이지만, 이 단언을 계산된 스타일로 「정리」하면 테스트가 조용히 공허해지는
  가드라 남긴다.

### `tokens.css`

- **제거 — `[hidden]` 규칙 머리**(물리 2줄). 「목업의 여정 레이어가 두는 규칙 그대로」 는 목업 여정
  페이지들의 `[hidden]{display:none !important}` 축자(②)이고, 「없으면 배너가 제출 전부터 보인다」 는
  PR #204 본문 첫 불릿(③)이다. 편집 지점 가드 단서도 여기서는 서지 않는다 — 규칙을 지우거나
  `!important` 를 빼면 `Trend.test.tsx` 의 `ships a [hidden] rule that outranks the banners' own display`
  가 **즉시 붉고**, 그 테스트 머리 3줄이 같은 명제의 주인이다(한 사실이 두 파일에 사본으로 있던 자리 —
  설명은 테스트 쪽에만 둔다).
- **개작 — `≤1180px` `trend` 덮어쓰기 머리 물리 4줄 → 1줄.** 무엇을 하는지(옆 칸·스캔 요약을 전폭으로,
  옆 칸은 두 칸 나란히)는 바로 아래 선언과 설계 트래커의 #204 행(「`≤1180px` 반 폭 규칙의 `trend` 한정
  덮어쓰기」)이 축자로 복원한다(①②). 남긴 것은 「`.col-*` 와 겹쳐 적는 것은 뒤쪽 공용 규칙보다 우선하기
  위해서」 — 누가 선택자를 `.trend-side` 로 줄이면 뒤쪽 공용 `≤1180px` 블록에 **조용히 지는** 순서 가드다.
- **유지 — `.sidebar-rail` 머리.** 트래커 #204 「구현 전용 — 레일」 행이 같은 사유를 적는다(②). 그러나 레일을
  걷어도 브라우저에서는 스티키가 따라와 아무 차이가 없고 **전체 페이지 캡처에서만** 깨진다 — 테스트도
  게이트도 붙잡지 않는 무음 파손이고, 편집 지점에서 트래커는 읽히지 않는다. 판단이 갈리는 자리라 남긴다.
- **유지 — `.dbg-metric` 머리.** 「이 값이 무엇과 같아야 하는가」(목업 `JRN-judgment-debug.html` 의 인라인
  `style` 값)를 말하는 가드다. `check-mockup-render.py` R5 는 접두 선택자를 대조하지 않으므로
  (residual-close-pass 가 `.dash-` 배너 주석을 걷은 근거가 여기서는 서지 않는다) 값이 갈라져도 초록이다.

`CMP-*` / `PAT-*` / `STP-*` / `TKN-*` 마커는 한 줄도 건드리지 않았다.
