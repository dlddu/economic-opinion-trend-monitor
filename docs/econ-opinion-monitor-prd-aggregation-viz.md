# PRD: 정규화·집계·시각화 (Aggregation / Gold + Serving)

> 대응 요구사항: ③번 — "핵심 서술 대상 기준 트렌드·비율 시각화 (API별 수집 개수 차이는 정규화 처리)"
> 데이터 레이크 계층: **Gold (정규화·집계) + Serving (시각화)**

## 달성 가치
- **V1 (시계열 추세 가시화)** — 서술 대상 기준 시계열 집계와 추세 차트를 제공한다.
- **V2 (지역 축 간 비교)** — 3개 축을 나란히 비교하는 뷰를 제공한다.
- **V3 (분위기 분포 파악)** — 분위기 비율을 시각화한다.
- **V4 (수집원 편차 보정)** — 소스별 수집량 차이를 정규화해 공정한 비교를 보장한다.

## 개요

Silver 계층의 분석 결과를 정규화·집계하여 Gold 계층에 적재하고, 이를 시각화로 서빙한다.
핵심 과제는 **소스마다 수집 가능한 뉴스 개수가 다르다는 점이 비교 결과를 왜곡하지 않도록**
정규화하는 것이다. 시각화는 핵심 서술 대상을 기준으로 추세와 비율을 보여준다.

## Acceptance Criteria

### AC3.1: 소스별 수집량 차이 정규화
- **설명**: 비율·추세 계산 시 절대 수집 건수가 큰 소스가 결과를 지배하지 않도록 정규화한다.
  예컨대 각 소스 내 점유율(share)을 먼저 계산한 뒤 축 단위로 결합하는 방식으로,
  소스 간 수집량 격차가 비교 결과를 왜곡하지 않아야 한다. 정규화 방식은 명시되고 일관 적용된다.
- **달성 가치**: V4
- **검증 방법**: 한 소스의 수집량만 인위적으로 늘렸을 때 정규화된 비율이 과도하게 흔들리지 않는지 확인한다.

### AC3.2: 핵심 서술 대상 기준 집계
- **설명**: Silver의 핵심 서술 대상(AC2.2)을 키로 빈도·점유율을 집계한다. 표기 변형이 통합된
  동일 키로 묶이며, 축·시간대 등 차원과 교차 집계가 가능하다.
- **달성 가치**: V1
- **검증 방법**: 동일 대상이 하나의 집계 키로 모이고, 차원별 교차 집계 결과가 정확한지 확인한다.

### AC3.3: 시계열 추세 집계 (시간 단위)
- **설명**: 수집 시각(AC1.5)을 기준으로 시간대별 집계를 만들어 서술 대상의 관심도 변화를
  시계열로 추적한다. 기본 단위는 시간이며, 더 긴 구간(일·주)으로 롤업할 수 있다.
- **달성 가치**: V1
- **검증 방법**: 시간대별 버킷이 누락 없이 생성되고, 롤업 시 합산이 일관되는지 확인한다.

### AC3.4: 축별·분위기별 비율 집계
- **설명**: 한국·미국·전세계 축별로, 그리고 분위기(긍정/중립/부정/혼합)별로 비율을 집계한다.
  저신뢰/미분석(AC2.5)은 비율 집계에서 분리하거나 별도 항목으로 표시한다.
- **달성 가치**: V2, V3
- **검증 방법**: 축·분위기 조합별 비율 합이 정합적이고, 미분석 항목이 구분되는지 확인한다.

### AC3.5: 서술 대상별 추세 시계열 시각화
- **설명**: 핵심 서술 대상의 시간대별 관심도 추세를 차트로 보여준다. 상위 대상 비교,
  특정 대상 선택 조회가 가능하다.
- **달성 가치**: V1
- **검증 방법**: 차트가 집계 데이터와 일치하고, 대상 선택·비교가 동작하는지 확인한다.

### AC3.6: 분위기 비율 시각화
- **설명**: 서술 대상 또는 축 단위로 긍정/중립/부정/혼합 비율을 시각화한다.
- **달성 가치**: V3
- **검증 방법**: 분위기 비율 시각화가 집계값과 일치하는지 확인한다.

### AC3.7: 3축 비교 뷰
- **설명**: 한국·미국·전세계 3개 축을 같은 화면/기준으로 나란히 비교하는 뷰를 제공한다.
  같은 시점에 축마다 상위 서술 대상과 분위기가 어떻게 다른지 대조할 수 있다.
- **달성 가치**: V2
- **검증 방법**: 동일 시점·기준에서 3개 축이 정렬되어 비교 가능한지 확인한다.

### AC3.8: 정규화된 비율 표시 (원시 카운트와 구분)
- **설명**: 시각화에 표시되는 값이 정규화된 비율임을 명확히 하고, 필요 시 원시 수집 건수와
  구분해 함께 제공한다. 사용자가 보정된 비교를 보고 있음을 인지할 수 있어야 한다.
- **달성 가치**: V4
- **검증 방법**: 정규화 비율과 원시 카운트가 구분 표기되고, 정규화 적용 여부가 드러나는지 확인한다.
