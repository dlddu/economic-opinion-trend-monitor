# 테스트 문서: LLM 분석 파이프라인 검증

## 검증 대상 AC
- AC2.1: 대상 국가 추출 (PRD: LLM 분석 파이프라인)
- AC2.2: 핵심 서술 대상 추출 (PRD: LLM 분석 파이프라인)
- AC2.3: 분위기 4분류 (PRD: LLM 분석 파이프라인)
- AC2.4: Silver 정규화 스키마 저장 (PRD: LLM 분석 파이프라인)
- AC2.5: 저신뢰·분석 불가 처리 (PRD: LLM 분석 파이프라인)
- AC2.6: Bronze → Silver 추적 키 유지 (PRD: LLM 분석 파이프라인)
- AC2.7: 분석 로직 버전의 프롬프트 파생 (PRD: LLM 분석 파이프라인)

## 테스트 시나리오

### 시나리오 1: 대상 국가 추출 (단일·다국가·글로벌)
- **사전 조건**: 단일 국가 대상 기사, 복수 국가 대상 기사, 특정 국가에 한정되지 않는 글로벌
  이슈 기사를 준비한다.
- **실행 단계**: 세 기사를 분석한다.
- **기대 결과**: 단일 기사는 해당 국가, 다국가 기사는 복수 국가, 글로벌 기사는 GLOBAL/해당 없음으로
  분류되며, 이 값이 수집 출처 축과 별개임이 유지된다.
- **검증 AC**: AC2.1

### 시나리오 2: 핵심 서술 대상 추출과 표기 변형 통합
- **사전 조건**: 동일 대상을 약칭·정식명 등 다른 표기로 지칭하는 복수 기사를 준비한다.
- **실행 단계**: 기사들을 분석하고 추출된 서술 대상 키를 비교한다.
- **기대 결과**: 표기 변형이 하나의 정규화된 키로 모이고, 핵심 대상이 누락 없이 추출된다.
- **검증 AC**: AC2.2

### 시나리오 3: 분위기 4분류 정확성
- **사전 조건**: 긍정·중립·부정·혼합 각각의 대표 기사를 준비한다.
- **실행 단계**: 네 기사를 분석한다.
- **기대 결과**: 각 기사에 기대 라벨이 부여되고, 상반 톤 공존 기사는 '혼합', 톤이 드러나지 않는
  기사는 '중립'으로 일관되게 분류된다.
- **검증 AC**: AC2.3

### 시나리오 4: 다중 값 손실 없는 저장
- **사전 조건**: 다국가·복수 서술 대상을 가진 기사를 준비한다.
- **실행 단계**: 분석 결과를 Silver에 적재하고 Gold 집계에서 조회한다.
- **기대 결과**: 다중 값이 손실 없이 정규화 스키마로 저장되고, 후속 집계에서 그대로 조회된다.
- **검증 AC**: AC2.4

### 시나리오 5: 저신뢰·미분석 표시 및 분리
- **사전 조건**: 본문이 부족한 기사와 톤·대상이 모호한 기사를 준비한다.
- **실행 단계**: 두 기사를 분석하고 집계 단계에서 처리 결과를 확인한다.
- **기대 결과**: 결과가 강제로 채워지지 않고 저신뢰/미분석으로 표시되며, 집계·시각화에서
  정상 분석 항목과 구분된다.
- **검증 AC**: AC2.5

### 시나리오 6: 원문 역추적과 재분석 키 유지
- **사전 조건**: Silver에 적재된 분석 레코드가 있다.
- **실행 단계**: (1) 임의 Silver 레코드에서 Bronze 원문(링크·본문)으로 도달을 시도한다.
  (2) 분석 로직을 변경해 동일 Bronze 원문을 재분석한다.
- **기대 결과**: 모든 Silver 레코드가 대응 Bronze 원문으로 역추적되고, 재분석 후에도 추적 키가
  유지되어 Silver가 갱신된다.
- **검증 AC**: AC2.6

### 시나리오 7: 프롬프트가 바뀌면 버전이 바뀐다
- **사전 조건**: 같은 Bronze 원문 묶음이 있다. 프롬프트(시스템 프롬프트 또는 사용자 프롬프트 템플릿)만
  한 곳 다르고 나머지는 같은 분석기 A와 A′를 준비한다.
- **실행 단계**: (1) A로 분석한다. (2) 같은 원문을 A로 한 번 더 분석한다. (3) A′로 범위 지정 재처리를
  한다. (4) A′ 실행에 다른 버전 문자열을 수동 지정해 한 번 더 시도한다. (5) 각 버전에서 프롬프트 원문을
  조회한다.
- **기대 결과**: (1)과 (2)의 버전이 같고, (3)의 버전은 그와 다르며 Silver에 두 버전이 서로 구분되어 남는다.
  (4)의 수동 지정은 거부되거나 라벨로만 붙고 파생 부분은 (3)과 같다. 각 버전의 모든 호출 기록이 같은
  시스템 프롬프트 해시를 가지며, 버전에서 조회한 프롬프트가 그 호출 기록의 전송 프롬프트와 일치한다.
- **검증 AC**: AC2.7
