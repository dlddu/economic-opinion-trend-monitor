mockup (화면 단위)

여정 단위로 전환되기 전의 화면 단위 산출물. 여정 문서의 "시각화 현황"은 mockup 0개로 적혀 있어 실제(7화면)와 어긋난다 — 여정 문서 갱신 필요.

화면 단위 mockup 갤러리 dashboard · trend · compare · sentiment · fairness · trace · reprocess 갤러리 열기 → mockup 인덱스
이 페이지는 손으로 갱신한다. 여정·mockup·문서가 늘거나 줄면 같은 커밋에서 이 파일도 고친다.
