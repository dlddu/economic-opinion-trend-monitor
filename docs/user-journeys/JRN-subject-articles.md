## 1. 서비스 개요 (참고)

**경제 여론 추세 모니터** — 한국·미국·전세계 3축의 조회수 상위 경제 뉴스를 매시간 수집해, 서술 대상별 관심 추세와 분위기를 시각화한다.

제품 가치 정의는 `docs/econ-opinion-monitor-values.md` 참조.

## 2. 여정 정의

**대상 사용자 (페르소나)**
정민서(가명), 34세, 증권사 리서치센터 애널리스트 (가정). 리포트에 인용할 숫자는 근거를 확인하고 쓴다. "왜 이 숫자가 이렇게 나왔는지" 설명할 수 없는 데이터는 쓰지 않는다.

**진입 맥락**
`JRN-subject-share` 순위에서 대상을 골라 들어오거나, `JRN-subject-trend` 의 변화 지점·`JRN-subject-sentiment` 의 분위기 구간·`JRN-source-share` 의 셀에서 그 조건을 유지한 채 들어온다.

**트리거**
대상의 비율이 튀었거나 의외여서 "실제로 어떤 기사들이, 어디서 잡힌 거지"를 확인하고 싶다.

**사용자 목표**
그 대상 비율을 만든 기사들이 여러 출처에 고르게 퍼져 있는지 한 출처에 쏠려 있는지 판단하고, 필요하면 원문과 분석 근거까지 확인한다.

**완료 기준**
출처 구성 요약을 본 뒤 원문 1건 이상을 연다. 로그로는 원문 목록 진입 + 원문 열람 이벤트로 확인.

## 3. 단계별 상세

> 단계 식별자는 순번이 아닌 슬러그를 쓴다. 순서가 바뀌어도 식별자는 유지한다.

### `STP-open-article-list` 기여 기사 목록 열기

- **사용자 행동**: 승계된 조건(축·기간 또는 버킷, 들어온 경로에 따라 출처·분위기)에서 그 대상으로 집계된 기사 목록을 연다 (AC3.12, AC3.2)
- **터치포인트**: 원문 목록 화면 — 조건 표기 · 기사 행(제목 · 출처 · 수집 시각 · 분위기 · 본문 중복 여부)
- **생각·감정**: "실제로 무슨 기사들이 잡힌 거야"
- **페인포인트 / 이탈 위험**: 제목만 나열되면 같은 사건의 재탕인지 구분이 안 된다 → 출처·수집 시각·본문 중복 여부(AC1.7)를 행에 함께 표기
- **페인포인트 / 이탈 위험**: 목록 건수가 순위 화면의 원시 건수와 다르면 다른 계산을 의심한다 → 목록은 집계와 같은 기사 집합(같은 기사는 한 번)이고 건수가 원시 건수와 같음을 보장

### `STP-read-source-mix` 출처 구성 요약 확인

- **사용자 행동**: 목록 위 요약에서 출처별 기사 수와 정규화 후 기여 비중을 보고, 한 출처에 쏠렸는지 판단한다 (AC3.12)
- **터치포인트**: 목록 위 출처 구성 요약(출처 · 건수 · 정규화 후 기여 비중 · 최다 출처 비중)
- **생각·감정**: "12건이 연합이네, 한 곳이 많이 쓴 거였구나" / "여러 곳에 퍼져 있네, 진짜 관심이다"
- **페인포인트 / 이탈 위험**: 요약이 없으면 목록을 스크롤하며 직접 세야 한다 → 출처별 건수를 목록 위에 상시 요약
- **페인포인트 / 이탈 위험**: 건수와 기여 비중이 왜 다른지 모르면 정규화를 불신한다 → 기여 비중이 기사 수 제곱근 가중의 결과임을 요약 머리에 명시

### `STP-filter-source` 출처로 좁히기

- **사용자 행동**: 요약의 출처를 눌러 그 출처 기사만 남긴다
- **터치포인트**: 출처 구성 요약 행(누르면 필터) · 적용 중 필터 표기
- **생각·감정**: "연합 건 말고 나머지는 뭐였지"
- **페인포인트 / 이탈 위험**: 필터가 걸린 줄 모르면 목록이 줄어든 이유를 오해한다 → 적용 중 필터를 목록 머리에 표기하고 한 번에 해제

### `STP-open-article` 원문·분석 근거 열기

- **사용자 행동**: 기사 하나를 열어 보존된 원문 전체와 원문 링크, 그리고 분석 결과(서술 대상 · 카테고리 · 분위기)와 판단 근거를 확인한다 (AC2.6, AC1.4, AC2.3)
- **터치포인트**: 원문 상세 — 원문 전체 · 원문 링크(상태 배지) · 분석 결과 · 분위기 판단 근거
- **생각·감정**: "분류가 맞게 됐네" / "이건 이 대상 기사가 아닌데?"
- **페인포인트 / 이탈 위험**: 원문 링크가 만료되면 추적이 끊긴다 → 보존된 원문 전체를 링크 상태와 무관하게 열람 가능하게
- **여정 종료**: 이 단계가 마지막이다

## 4. 분기·예외 흐름

| 상황 | 처리 | 이어지는 단계 |
|---|---|---|
| 원문 링크 만료·404 | 보존 원문 전체를 대체 표시하고 링크 상태를 배지로 명시 | `STP-open-article` |
| 미분석 기사가 섞여 있음 (AC2.5) | 분위기 칸을 「미분석」으로 표기하고 필터로 분리 가능 | `STP-open-article-list` |
| 분류 오류를 발견함 (기사가 이 대상이 아님) | 운영 재처리 흐름으로 인계 | `JRN-logic-backfill` · `STP-scope-range` |
| 같은 기사가 중복 수집된 것으로 의심됨 | 운영 무결성 흐름으로 인계 | `JRN-ingestion-recovery` · `STP-spot-anomaly` |
| 대상의 추세를 보고 싶어짐 | 조건을 승계해 추세로 | `JRN-subject-trend` · `STP-open-subject-trend` |
