## 1. 서비스 개요 (참고)

**경제 여론 추세 모니터** — 한국·미국·전세계 3축의 조회수 상위 경제 뉴스를 매시간 수집해, 서술 대상별 관심 추세와 분위기를 시각화한다.

제품 가치 정의는 `docs/econ-opinion-monitor-values.md` 참조.

관찰자 여정은 이 여정을 **허브**로 두고 갈라진다. 여기서 대상을 고르면 `JRN-subject-sentiment`(분위기) · `JRN-subject-articles`(원문) · `JRN-subject-trend`(추세)로 들어가고, 비교가 목적이면 `JRN-source-share`(출처별) · `JRN-axis-share`(축별)로 간다.

## 2. 여정 정의

**대상 사용자 (페르소나)**
정민서(가명), 34세, 증권사 리서치센터 애널리스트 (가정). 매일 시장 브리핑을 준비한다. 뉴스 텍스트를 직접 읽을 시간은 없고 "무엇이 뜨고 있나"를 먼저 잡은 뒤 필요한 것만 파고든다. 리포트에 인용할 숫자는 근거를 확인하고 쓴다.

**진입 맥락**
제품을 열면 처음 보는 화면이다. 출근 직후 습관적으로 열거나(가정), 다른 여정에서 조회 조건을 바꾸러 돌아온다.

**트리거**
"지금 경제 여론의 관심이 어디에 몰려 있나"를 알고 싶다.

**사용자 목표**
선택한 범위(축·기간)에서 서술 대상별 비율 순위와 직전 기간 대비 증감을 파악하고, 더 들여다볼 대상을 고른다.

**완료 기준**
대상 비율 순위를 연 뒤, 대상 1개를 골라 `JRN-subject-sentiment`·`JRN-subject-articles`·`JRN-subject-trend` 중 하나로 진입. 로그로는 순위 화면 진입 + 대상 선택 이벤트로 확인.

## 3. 단계별 상세

> 단계 식별자는 순번이 아닌 슬러그를 쓴다. 순서가 바뀌어도 식별자는 유지한다.

### `STP-set-scope` 조회 조건 맞추기

- **사용자 행동**: 축(전체·한국·미국·전세계) · 기간(24시간/7일/30일) · 집계 단위(시간/일/주)를 고른다. 고르는 즉시 반영된다 (AC3.3)
- **터치포인트**: 화면 맨 위 조회 조건 카드
- **생각·감정**: "어제 하루 기준으로, 전체에서 보자"
- **페인포인트 / 이탈 위험**: 진입할 때마다 조건이 초기화되면 다시 맞추는 마찰이 생긴다 → 마지막 조회 조건을 기본값으로 복원 (가정)
- **페인포인트 / 이탈 위험**: 「전체」가 어떻게 합쳐졌는지 모르면 축 하나가 결과를 지배한다고 오해한다 → 「전체」는 세 축 점유율의 균등 평균임을 조건 카드에 한 줄로 명시 (AC3.4)
- **페인포인트 / 이탈 위험**: 기간보다 길거나 같은 단위를 고르면 추이가 한 칸뿐이다 → 그런 단위는 선택지에서 뺀다

### `STP-scan-ranking` 비율 순위와 증감 훑기

- **사용자 행동**: 기간 전체로 센 대상 비율 순위와 직전 같은 길이 기간 대비 증감을 훑어, 새로 올라오거나 빠진 대상을 찾는다 (AC3.2, AC3.3)
- **터치포인트**: 상위 지표 카드 · 대상 순위 목록(비율 · 증감 · 기간 안 추이 스파크라인)
- **생각·감정**: "어제 여기 있었나? 못 보던 게 껴 있는데"
- **페인포인트 / 이탈 위험**: 현재 순위만 있고 변화가 없으면 매일 처음부터 다시 읽어야 한다 → 증감을 순위 목록에 기본 노출
- **페인포인트 / 이탈 위험**: 순위·비율·증감이 단위에 따라 바뀌면 「최근 30일」 순위가 사실은 오늘 하루 순위로 잘못 읽힌다 → 순위·비율·증감은 기간 전체를 한 번에 센 값, 단위는 추이 칸으로만 쓴다

### `STP-toggle-raw` 정규화 전/후 전환

- **사용자 행동**: 지금 보는 비율이 정규화 값임을 확인하고, 원시 건수로 바꿔 순위가 유지되는지 본다 (AC3.8)
- **터치포인트**: 순위 목록 머리의 정규화 전/후 전환 · 값 옆 정규화 표기
- **생각·감정**: "이게 몇 건짜리 비율이지? 정규화 안 하면 순위가 어떻게 되지"
- **페인포인트 / 이탈 위험**: 값의 종류가 표시되지 않으면 두 수치를 섞어 해석한다 → 모든 수치 옆에 정규화 여부를 상시 표기하고, 전환해도 고른 대상 하이라이트를 유지
- **페인포인트 / 이탈 위험**: 기사 몇 건짜리 출처가 비율을 끌어올린 것인지 순위에서는 알 수 없다 → 정규화 방식(출처별 기사 수의 제곱근 비례 가중)을 한 줄로 노출하고, 출처 구성은 `JRN-subject-articles` 로 보낸다

### `STP-pick-subject` 대상 골라 상세로

- **사용자 행동**: 눈에 걸린 대상을 골라 분위기·원문·추세 중 하나로 들어간다
- **터치포인트**: 순위 행의 세 갈래 진입(분위기 / 원문 / 추세)
- **생각·감정**: "이거 왜 올라왔지" / "분위기는 어떻지"
- **페인포인트 / 이탈 위험**: 상세로 가면서 조건을 잃으면 다시 맞춰야 한다 → 축·기간·단위·정규화 여부를 상세로 승계
- **여정 종료**: 이 단계가 마지막이다

## 4. 분기·예외 흐름

| 상황 | 처리 | 이어지는 단계 |
|---|---|---|
| 대상의 분위기를 보고 싶음 | 조건을 승계해 분위기 여정으로 | `JRN-subject-sentiment` · `STP-open-subject-sentiment` |
| 대상을 다룬 기사를 보고 싶음 | 조건을 승계해 원문 여정으로 | `JRN-subject-articles` · `STP-open-article-list` |
| 대상의 추세를 보고 싶음 | 조건을 승계해 추세 여정으로 | `JRN-subject-trend` · `STP-open-subject-trend` |
| 출처마다 관심사가 다른지 궁금함 | 출처별 비교로 이동 | `JRN-source-share` · `STP-open-source-matrix` |
| 축마다 관심사가 다른지 궁금함 | 축별 비교로 이동 | `JRN-axis-share` · `STP-open-axis-compare` |
| 수집이 비어 해당 기간 데이터가 없음 | 「데이터 없음」을 0 과 구분해 표시하고 마지막 정상 수집 시각 표기 | `STP-set-scope` |
| 중도 이탈 (순위만 보고 종료) | 다음 진입 시 마지막 조회 조건 복원 (가정) | `STP-set-scope` |
