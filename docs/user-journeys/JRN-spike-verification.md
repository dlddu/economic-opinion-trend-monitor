## 1. 서비스 개요 (참고)

**경제 여론 추세 모니터** — 한국·미국·전세계 3축의 조회수 상위 경제 뉴스를 매시간 수집해, 서술 대상별 관심 추세와 분위기를 시각화한다.

제품 가치 정의는 `docs/econ-opinion-monitor-values.md` 참조.

## 2. 여정 정의

**대상 사용자 (페르소나)**
정민서(가명), 34세, 증권사 리서치센터 애널리스트 (가정). 자신의 리포트에 인용할 수치는 근거를 확인하고 쓴다. "왜 이 숫자가 이렇게 나왔는지" 설명할 수 없는 데이터는 쓰지 않는다.

**진입 맥락**
`JRN-daily-scan` 또는 `JRN-axis-contrast` 중 특정 대상의 값이 비정상적으로 튄 것을 보고 넘어온다. 단독 진입은 드물다.

**트리거**
한 서술 대상의 언급량·점유율이 평소 대비 눈에 띄게 급등했고, 그것이 실제 여론인지 한 소스의 도배인지 판단이 서지 않는다.

**사용자 목표**
급등이 정규화 이후에도 유효한 신호인지, 아니면 특정 수집원 편중이 만든 착시인지 판정하고, 필요하면 원문까지 내려가 근거를 눈으로 확인한다.

**완료 기준**
정규화 값과 원시 카운트를 모두 확인하고, 최소 1건의 Bronze 원문에 도달 — 또는 "정규화 후 유효" 판정으로 원문 확인 없이 종료. 두 경우 모두 사용자가 판정 근거를 말할 수 있는 상태. 로그로는 정규화 토글 사용 + 원문 링크 클릭으로 확인.

## 3. 단계별 상세

### `STP-notice-spike` 이상 급등 인지

- **사용자 행동**: 추세·순위에서 튀는 값을 발견하고 "이거 진짜인가" 의심을 품는다
- **터치포인트**: `dashboard.html` 순위 목록 / `trend.html` 라인 차트
- **생각·감정**: "갑자기? 이 정도로 올라올 이슈가 아닌데"
- **페인포인트 / 이탈 위험**: 의심이 들어도 검증 경로가 안 보이면 그냥 데이터를 불신하고 떠난다 → 급등 지점에서 공정성 화면으로 가는 진입점을 노출

### `STP-check-normalized` 정규화/원시 전환 확인

- **사용자 행동**: 지금 보는 값이 정규화 비율인지 원시 카운트인지 확인하고 토글해 양쪽을 비교한다 (AC3.8)
- **터치포인트**: `fairness.html` 정규화 토글(`CMP-norm-toggle`), 원시↔정규화 대비 패턴(`PAT-raw-vs-norm`)
- **생각·감정**: "정규화하면 이 순위가 유지되나?"
- **페인포인트 / 이탈 위험**: 화면 어디에도 지금 값의 종류가 표시되지 않으면 두 수치를 섞어 해석한다 → 모든 수치 옆에 정규화 여부를 상시 명시

### `STP-inspect-sources` 소스 구성 확인

- **사용자 행동**: 이 대상의 언급이 어느 수집원에서 얼마나 왔는지 분해해서 본다 (AC3.1)
- **터치포인트**: `fairness.html` 소스별 기여 테이블(`CMP-table`)
- **생각·감정**: "한 군데서 다 나온 거면 신호가 아니라 잡음이지"
- **페인포인트 / 이탈 위험**: 소스별 분해가 없으면 정규화를 믿을 수 있는지도 확인할 수 없다 → 소스별 기여 비중을 원시·정규화 양쪽으로 제시

### `STP-drilldown-articles` 기여 뉴스 목록으로 내려가기

- **사용자 행동**: 해당 데이터 포인트에 기여한 개별 뉴스 목록을 연다 (AC3.2)
- **터치포인트**: `fairness.html` 기여 뉴스 행 → `trace.html`
- **생각·감정**: "실제로 무슨 기사들이 잡힌 거야"
- **페인포인트 / 이탈 위험**: 목록이 제목만 나열되면 같은 사건의 재탕인지 구분이 안 된다 → 소스·수집 시각·본문 중복 여부(AC1.7)를 목록에 함께 표기

### `STP-open-origin` 원문 역추적

- **사용자 행동**: 개별 뉴스의 Bronze 원문 링크·원문 전체로 도달해 분류 근거를 확인한다 (AC2.6, AC1.4)
- **터치포인트**: `trace.html` 계보 패턴(`PAT-lineage`), 원문 링크
- **생각·감정**: "분류가 맞게 됐네" 또는 "이건 이 대상 기사가 아닌데?"
- **페인포인트 / 이탈 위험**: 원문 링크가 만료·삭제되어 열리지 않으면 추적이 거기서 끊긴다 → Bronze에 보존된 원문 전체를 링크 실패와 무관하게 열람 가능하게

### `STP-judge` 판정과 종료

- **사용자 행동**: "유효한 신호" 또는 "수집 편중" 중 하나로 판단하고 세션을 닫는다
- **터치포인트**: `trace.html` / 제품 외부(리포트·메모)
- **생각·감정**: "이건 써도 되겠다" / "이건 빼자"
- **페인포인트 / 이탈 위험**: 판정 결과가 제품에 남지 않아 같은 대상을 다음에 또 검증한다 → 검증 이력·플래그 남기기 (현재 범위 밖, 백로그 후보)

## 4. 분기·예외 흐름

| 상황 | 처리 | 이어지는 단계 |
|---|---|---|
| 원문 링크 만료·404 | Bronze 보존 원문 전체를 대체 표시하고 링크 상태를 배지로 명시 | `STP-open-origin` |
| 저신뢰·미분석 항목이 섞여 있음 (AC2.5) | 집계에서 분리 표기하고 별도 항목으로 노출 | `STP-inspect-sources` |
| 분류 오류를 발견함 (기사가 이 대상이 아님) | 운영 재처리 흐름으로 인계 | `JRN-logic-backfill` · `STP-scope-range` |
| 급등이 수집 이상(중복 수집)으로 의심됨 | 운영 무결성 흐름으로 인계 | `JRN-ingestion-recovery` · `STP-spot-anomaly` |
| 정규화 후 급등이 사라짐 | 원문 확인 없이 "편중" 판정으로 조기 종료 | `STP-judge` |
