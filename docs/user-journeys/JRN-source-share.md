## 1. 서비스 개요 (참고)

**경제 여론 추세 모니터** — 한국·미국·전세계 3축의 조회수 상위 경제 뉴스를 매시간 수집해, 서술 대상별 관심 추세와 분위기를 시각화한다.

제품 가치 정의는 `docs/econ-opinion-monitor-values.md` 참조.

**출처와 축.** 출처는 개별 피드 하나(현재 18개)이고, 축은 출처를 수집 지역으로 묶은 그룹이다(출처마다 축 하나 고정, AC1.3). 축 단위 비교는 `JRN-axis-share` 가 맡는다.

## 2. 여정 정의

**대상 사용자 (페르소나)**
정민서(가명), 34세, 증권사 리서치센터 애널리스트 (가정). 매체마다 관심사가 다르다는 걸 안다. 합쳐진 비율 뒤에서 어느 매체가 무엇을 밀고 있는지 보고 싶어 한다.

**진입 맥락**
`JRN-subject-share` 에서 「출처마다 다른가」가 궁금해 넘어오거나, 정규화된 비율이 의외일 때 출처 쪽에서 원인을 찾으려 들어온다.

**트리거**
"이 대상은 어느 매체가 많이 다루고, 어느 매체는 안 다루나" / "매체마다 관심사가 얼마나 다른가".

**사용자 목표**
출처 × 대상 전체 표에서 출처마다의 대상 비율을 한눈에 보고, 특정 출처에 쏠린 대상이나 특정 대상에 쏠린 출처를 찾는다.

**완료 기준**
출처 × 대상 표를 연 뒤, 행 또는 열 기준 정렬·강조를 1회 이상 하거나 셀을 골라 대상 상세로 진입. 로그로는 표 진입 + 정렬·셀 선택 이벤트로 확인.

## 3. 단계별 상세

> 단계 식별자는 순번이 아닌 슬러그를 쓴다. 순서가 바뀌어도 식별자는 유지한다.

### `STP-open-source-matrix` 출처 × 대상 표 열기

- **사용자 행동**: 기간을 고르고 출처(행) × 대상 카테고리(열) 전체 표를 연다. 셀은 **그 출처 안에서** 그 대상이 차지한 비율이다 (AC3.11)
- **터치포인트**: 출처별 비교 화면 — 기간 선택 · 축으로 출처 묶음 접기/펼치기 · 색 농도 표(18 × 25) · 행 끝 출처 기사 수
- **생각·감정**: "매체마다 확실히 다르네"
- **페인포인트 / 이탈 위험**: 출처 간 가중이 없는 값이라는 걸 모르면 다른 화면의 정규화 비율과 비교해 혼란스러워한다 → 「셀 = 출처 내 비율」을 표 머리에 명시
- **페인포인트 / 이탈 위험**: 18 × 25 가 한 화면에 안 들어간다 → 출처는 축별로 묶어 접고, 대상 열은 전체 비율 순으로 정렬해 상위부터 보이게

### `STP-switch-count` 비율 ↔ 건수 전환

- **사용자 행동**: 셀 값을 비율에서 기사 건수로 바꿔, 기사 몇 건짜리 비율인지 본다 (AC3.8)
- **터치포인트**: 표 머리의 비율/건수 전환 · 행 끝 출처 기사 수
- **생각·감정**: "Fed 금리 100% 는 2건짜리였네"
- **페인포인트 / 이탈 위험**: 기사가 적은 출처의 비율이 진하게 칠해져 과대평가된다 → 출처 기사 수가 최소 표본 미만인 행은 흐리게 처리하고 「표본 부족」 표기

### `STP-scan-source-bias` 쏠림 찾기

- **사용자 행동**: 행(출처)이나 열(대상)을 기준으로 정렬·강조해, 한 출처에 쏠린 대상이나 한 대상에 쏠린 출처를 찾는다
- **터치포인트**: 행·열 머리 정렬 · 선택 행·열 강조
- **생각·감정**: "반도체는 한경·매경만 많이 쓰네"
- **페인포인트 / 이탈 위험**: 표가 크면 눈으로 쏠림을 찾기 어렵다 → 열을 고르면 그 대상 비율 순으로 출처를 정렬하고, 행을 고르면 그 출처의 대상 비율 순으로 정렬

### `STP-pick-cell` 셀 골라 상세로

- **사용자 행동**: 셀(출처 × 대상)을 골라 그 출처 조건을 유지한 채 분위기·원문·추세로 들어간다
- **터치포인트**: 셀 선택 → 세 갈래 진입(분위기 / 원문 / 추세)
- **생각·감정**: "이 매체는 이 대상을 어떻게 쓰고 있지"
- **페인포인트 / 이탈 위험**: 상세로 가면서 출처 조건을 잃으면 전체 값과 섞인다 → 출처 조건을 승계하고 상세 머리에 고정 표기
- **여정 종료**: 이 단계가 마지막이다

## 4. 분기·예외 흐름

| 상황 | 처리 | 이어지는 단계 |
|---|---|---|
| 그 출처의 대상 기사를 보고 싶음 | 출처·대상 조건을 승계해 원문 목록으로 | `JRN-subject-articles` · `STP-open-article-list` |
| 그 출처의 대상 분위기를 보고 싶음 | 출처·대상 조건을 승계해 분위기로 | `JRN-subject-sentiment` · `STP-open-subject-sentiment` |
| 그 출처의 대상 추세를 보고 싶음 | 출처·대상 조건을 승계해 추세로 | `JRN-subject-trend` · `STP-open-subject-trend` |
| 축 단위로 보고 싶어짐 | 축별 비교로 이동 | `JRN-axis-share` · `STP-open-axis-compare` |
| 출처 하나가 기간 내 수집 0건 | 행을 「수집 없음」으로 표시하고 0 비율로 칠하지 않음 | `STP-open-source-matrix` |
| 출처 수집이 장시간 멈춘 것으로 보임 | 운영 무결성 흐름으로 인계 | `JRN-ingestion-recovery` · `STP-spot-anomaly` |
