## 1. 서비스 개요 (참고)

**경제 여론 추세 모니터** — 한국·미국·전세계 3축의 조회수 상위 경제 뉴스를 매시간 수집해, 서술 대상별 관심 추세와 분위기를 시각화한다.

제품 가치 정의는 `docs/econ-opinion-monitor-values.md` 참조.

## 2. 여정 정의

**대상 사용자 (페르소나)**
정민서(가명), 34세, 증권사 리서치센터 애널리스트 (가정). 매일 아침 시장 브리핑을 준비한다. 뉴스 텍스트를 직접 읽을 시간은 없고, "무엇이 뜨고 있나"를 먼저 잡은 뒤 필요한 것만 파고든다. 데이터가 왜 그렇게 나왔는지 근거를 따지는 편이다.

**진입 맥락**
출근 직후 또는 장 시작 전, 습관적으로 대시보드를 연다. 특정 질문을 갖고 오지 않으며 "밤사이 뭐가 달라졌는지" 훑는 것이 목적이다.

**트리거**
매일 정해진 시각의 루틴 (가정 — 알림·구독 같은 능동 트리거는 아직 제품에 없음).

**사용자 목표**
밤사이 여론의 무게중심이 어디로 이동했는지 파악하고, 오늘 더 들여다볼 서술 대상을 몇 개 추린다.

**완료 기준**
관심 대상 1개 이상의 추세 상세(`trend`)를 열람하고 세션을 종료 — 즉 "목록만 보고 나감"이 아니라 최소 한 번 깊이 들어간 상태. 로그로 확인 가능.

## 3. 단계별 상세

### `STP-open-brief` 대시보드 열기

- **사용자 행동**: 기본 축·기본 기간 상태로 상위 서술 대상 목록을 연다
- **터치포인트**: `dashboard.html` (상단 지표 카드, 상위 대상 순위 목록)
- **생각·감정**: "밤사이 뭐가 올라왔나"
- **페인포인트 / 이탈 위험**: 기본 상태가 매번 초기화되면 축·기간을 다시 맞추는 마찰이 생긴다 → 마지막 조회 조건을 기본값으로 유지 (가정)

### `STP-scan-delta` 어제 대비 변화 훑기

- **사용자 행동**: 순위와 증감을 훑어 새로 올라온 대상·급락한 대상을 눈으로 찾는다
- **터치포인트**: `dashboard.html` 순위 목록의 증감 표시(`CMP-delta`)
- **생각·감정**: "어제 여기 있었나? 못 보던 게 껴 있는데"
- **페인포인트 / 이탈 위험**: 현재 순위만 보이고 직전 구간 대비 변화가 없으면 매일 처음부터 다시 읽어야 한다 → 직전 동일 구간 대비 증감을 순위 목록에 기본 노출

### `STP-adjust-window` 기간·단위 조정

- **사용자 행동**: 시간/일/주 단위를 바꿔 방금 본 변화가 일시적 스파이크인지 지속 추세인지 가늠한다 (AC3.3)
- **터치포인트**: `dashboard.html` 기간·단위 세그먼트 컨트롤(`CMP-seg`)
- **생각·감정**: "하루짜리 튐인가, 며칠째 오르는 건가"
- **페인포인트 / 이탈 위험**: 단위를 바꿀 때마다 순위가 크게 뒤집히면 어느 쪽을 믿을지 판단이 서지 않는다 → 단위 변경 시에도 직전 선택 대상을 하이라이트로 유지해 비교 가능하게

### `STP-drill-trend` 대상 추세 상세 열기

- **사용자 행동**: 눈에 걸린 대상을 골라 시계열 추세 차트를 연다 (AC3.5, AC3.2)
- **터치포인트**: `trend.html` (라인 차트, 상위 대상 비교 테이블)
- **생각·감정**: "언제부터 올라온 거지"
- **페인포인트 / 이탈 위험**: 상승 시작 시점에 무슨 일이 있었는지 알 수 없으면 추세만 보고 해석을 못 한다 → 데이터 포인트에서 기여 뉴스로 내려가는 경로 제공 (→ `JRN-spike-verification`)

### `STP-shortlist` 오늘 볼 대상 추리기

- **사용자 행동**: 2~3개 대상을 기억하거나 외부 메모로 옮기고 세션을 닫는다
- **터치포인트**: `trend.html` / 제품 외부(사용자 개인 메모)
- **생각·감정**: "일단 이 셋만 오늘 챙기자"
- **페인포인트 / 이탈 위험**: 제품 안에 담아두는 수단이 없어 매번 외부로 복사한다 → 관심 대상 북마크·워치리스트 (현재 범위 밖, 백로그 후보)

## 4. 분기·예외 흐름

| 상황 | 처리 | 이어지는 단계 |
|---|---|---|
| 밤사이 수집이 실패해 데이터가 비었음 | 빈 구간을 "데이터 없음"으로 명시(무응답과 0을 구분), 마지막 정상 수집 시각 표기 | `STP-scan-delta` (해석 보류) |
| 급등 대상이 신뢰되지 않음 | 정규화·원문 확인 흐름으로 이탈 | `JRN-spike-verification` · `STP-notice-spike` |
| 축 간 차이가 궁금해짐 | 3축 비교 흐름으로 이탈 | `JRN-axis-contrast` · `STP-open-compare` |
| 중도 이탈 (목록만 보고 종료) | 다음 진입 시 마지막 조회 조건 복원 (가정) | `STP-open-brief` |
