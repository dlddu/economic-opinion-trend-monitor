# 경제 여론 추세 모니터 문서 체계 상태 추적

> 이 문서는 가치 → PRD → AC → 테스트의 연결 상태를 추적하는 핵심 산출물이다.
> 문서를 생성·수정할 때마다 함께 갱신한다.

## 현재 상태 요약
- 정의된 가치: **5개** (V1~V5)
- PRD: **3개** (수집 / LLM 분석 / 정규화·집계·시각화)
- Acceptance Criteria: **20개** (가치 연결됨: 20개 / 미연결: 0개)
- 테스트 문서: **3개** (AC 커버됨: 20개 / 미커버: 0개)
- **건강 상태**: ⚠️ **위험 있음** — 제품 소유자 미지정으로 전 가치가 고아 가치 상태.
  연결 구조 자체(가치↔PRD↔AC↔테스트)는 끊김 없이 완전함.

## 위험 진단

### 🔴 고아 가치 (소유자 없는 가치)
- **V1~V5 전체** — 제품 소유자가 미지정 상태다. 가치를 정의·승인할 책임자가 지정되어야
  가치 변경 시 의사결정과 하위 문서 재검증의 주체가 명확해진다.
- **권장 조치**: 제품 소유자를 지정하고 가치 문서의 "제품 소유자" 항목과 본 위험을 갱신한다.

- (없음)

## 미해결 입력값
| 항목 | 현재 값 | 비고 |
|------|---------|------|
| 제품명 | 경제 여론 추세 모니터 (작업용) | 확정 시 갱신 |
| 제품 소유자 | 미지정 | 🔴 고아 가치 위험 — 지정 필요 |

## 변경 이력
| 시점 | 변경 내용 | 이전 상태 | 이후 상태 |
|------|-----------|-----------|-----------|
| 초기 생성 | V1~V5 가치 정의, 가치 문서 생성 | 가치 0개 | 가치 5개 |
| 초기 생성 | PRD-1/2/3 작성 | PRD 0개 | PRD 3개, AC 20개 |
| 초기 생성 | 테스트-1/2/3 작성 | 테스트 0개 | 테스트 3개, AC 20개 전부 커버 |
| 초기 생성 | 상태 추적 문서 초기화 | - | 건강 상태: 위험 있음(소유자 미지정) |
