# e2e Gold 픽스처

kind e2e가 서빙 경로(픽스처 Gold → Go API → 웹 렌더링) 검증에 쓰는 정적
데이터셋입니다. 배치 파이프라인 없이 결정적으로 검증하기 위해 커밋해 둡니다.

- 레코드는 `contracts/gold/*.avsc` 스키마를 그대로 따릅니다. 스키마를 바꾸면
  이 JSONL과 `tests/e2e/specs/`의 단언(픽스처 subject 문자열 등)을 함께
  갱신하세요. (코드 쪽 계약 드리프트는 `make gen-check`가 방어합니다.)
- subject는 smoke 테스트(`tests/smoke.sh`)의 값과 겹치지 않는 e2e 전용
  문자열(`E2E 검증 서브젝트`)을 사용해 단언 모호성을 없앱니다.
- **세 축(KR·US·GLOBAL)이 모두 채워져 있고, 모든 레코드가 같은 `time_bucket`**
  입니다. 3축 비교(AC3.7)는 "같은 시점에 축을 나란히 둔다"가 검증 대상이라 축
  하나라도 비면 단언이 공허해집니다. 축마다 상위 비율을 일부러 다르게 둬(KR 0.31
  · GLOBAL 0.27 · US 0.20) 축별 스케일과 공통 스케일이 구분되게 했습니다.
- 여러 버킷이 섞였을 때 비교가 어느 시점을 고르는지는 이 픽스처가 아니라
  `go/internal/handlers` 단위 테스트가 검증합니다 — 대시보드 spec들이 같은
  픽스처를 쓰므로 여기에 묵은 버킷을 넣지 않습니다.
